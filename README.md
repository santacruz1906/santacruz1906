# Santa Cruz from the kite camera, 1906 and now

A then-and-now slider: the George R. Lawrence Co. kite-camera panorama of Santa Cruz, California
(1906) beside today's city seen from the same point in the air.

Credits

- 1906 photograph: George R. Lawrence Co., Library of Congress, LC-USZ62-53410
  (https://www.loc.gov/item/2007663893/).
- Present-day view: Google Earth, imagery date 5/14/2024 (Google). Screen captures of the 3D model
  reprojected onto the 1906 print. It is a rendered model, not a photograph.

A personal, non-commercial hobby project.
